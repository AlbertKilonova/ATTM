# ATTM - 项目计划书

by Anming_cat

---

ATTM (ALambda Text To Midi) 是一个由 NET10 构建, 可以将纯文本转为 midi 的 windows wpf 应用程序

# 界面

深浅双色, 主题色 #FF4E6A (红色), 类似一个文本编辑器

字体: 系统默认字体(微软雅黑), Lekton 等宽字体("D:\Awork\Pi\ATTM\assets\Lekton")
图标: Material icon "D:\Awork\Pi\ATTM\assets\MSS-default.ttf"

上面: 工具栏
播放/暂停按钮(空格键), 停止重播按钮(ctrl+空格), 撤销(200次以内, ctrl+Z), 重做(ctrl+R), 打开文件按钮(ctrl+O), 创建新.attm文件按钮(ctrl+N), 保存按钮(ctrl+S), 设置按钮等

中间: 文本编辑器
显示行号, 使用等宽字体, 可以拖入或粘贴 txt 打开, ATTM 语法高亮, 播放时高亮显示具体播放到哪个音

下方: 状态栏
显示当前 midi 状态, 是否被保存及保存路径, 语法错误数等

设置界面: 设置主题颜色, 默认保存路径(windows系统音乐文件夹/ATTM)等等

保存界面: 设置保存文件名称, 路径等. 保存过一次后按ctrl+S可覆盖源文件快速保存无需重复打开界面
(保存时同时保存两个文件: 能重新被文本编辑器打开的.attm纯文本文件和导出的.mid文件)

# ATTM 语法

ATTM 是一种用文本快速标记 midi 音符的语言, 和 midi 不能无损转换, 为快速写谱而设计

## 基础 Midi 表示

ATTM 中, 在文件的开头需要先注明 bpm, 调式(自然大调)以及拍号

```
# 这是一行注释, 会直接被忽略掉
bpm = 120
1 = C 4/4 # 数字 1 表示调式主音，默认位于中央 C 所在八度；即 1 = C 时 1 是中央 C，1 = D 时 1 是 D4, 拍子为 4/4 拍, ATTM 仅支持 4/4 和 3/4 拍
```

使用数字简谱 1-7 来表示音符, 如高一个音域(升高一个八度即加12个半音)在前面加 `+`, 如低一个音域(降低一个八度即减12个半音)在前面加 `-`, 加 `#` 表示升高一个半音, +/-可以和#组合使用. (和注释不同的是, 这里 `#` 要紧接数字, 不能空格, 如 #4, +#4, 而注释用的 `#` 后面必须先接一个空格, 如`# 这是一行注释`)

```
1,+1,2,-2 # 表示依次弹奏1, 高八度的1, 2, 高八度的2
```

每一行是一个小节, 每拍之间用逗号分开, 在4/4拍中, 每行只能有 0 个, 1 个或 3 个逗号.
(0个逗号, 只有一个数字表示该数字持续一个小节; 1个逗号, 该行每段数字占二分之一小节; 3个逗号则每段数字占四分之一个小节. 在4/4拍中, 一行只有2个逗号不合法)

```
1

1,0

1,0,0,0

# 这三行是等价的, 都表示演奏一个全音符
```

拍子内可以有大于一个的数字, 连在一起不空格. 
一拍子只有一个音时: 数字代表四分音符 `1,4,5,7`
一拍子有两个音时: 每个数字代表八分音符 `11,12,3,05`
一拍子有八个音时: 每个数字代表十六分音符 `1134,5,12,0057` , 以此类推

`0` 表示该位置没有音符或是表示休止, 在 ATTM 中, 音符会自动连奏(即音符的时值持续到直到下一个音符或小节的末尾自动停止)
如 `05` 表示 5 前面先空八分之一拍, `0005` 表示 5 前面先空三个十六分之一拍.

若出现一拍子有非 1 或 2的 n 次方个的数字, 如`123,12345,123,456789`,则报错

```
# 欢乐颂 - 片段
bpm = 120
1 = C 4/4
Vel = 100 +-20 # 默认力度100, 随机力度抖动+-20, 若超过上下限则算最大/小力度, 可省略, 默认力度 90 +-0
# 不允许无空格的写法, bpm=120是错误的, bpm允许小数点

3,3,4,5

5,4,3,2

1,1,2,3

3,02,2,0

```

## 和弦 Midi 表示

可以用 `()` 来表示同时演奏的音符, 被括号的数字是一个整体, 看作是一个数字, 例如

```
(46+1),(57+2),(357),(6+1+3) # 表示 F-G-Em-Am 和弦进行, 每个和弦占四分之一小节

0(46+1),0(57+2),0(357),0(6+1+3) # 表示反拍演奏 F-G-Em-Am 和弦进行, 先空八分之一小节再演奏和弦
```

也可用多行不空行的小节来表示

```
4,5,3,6
6,7,5,+1
+1,+2,7,+3 
# 以上是同时演奏的

4,5,3,6

6,7,5,+1

+1,+2,7,+3

# 以上是先演奏4,5,3,6, 然后6,7,5,+1, 然后+1,+2,7,+3
```

## 一些细节

有语法错误时, 禁止播放/导出/保存.

midi默认源信息(不需要加入语法):
PPQ = 480
默认乐器/音色，Program 0 钢琴
默认力度 = 90 +-0
通道分配统一分配第一个, 多声部为单轨, 导出时合并
同音高重叠则覆盖
